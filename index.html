DÚVIDAS FREQUENTES

Perguntas frequentes

Os produtos são físicos?

Não. Todos os materiais são digitais, em formato Excel (.xlsx) ou PDF.

Como vou receber meu produto?

Quando o checkout estiver disponível, a entrega será feita pela plataforma de pagamento configurada para cada produto.

Preciso ter Excel?

Para aproveitar todas as funções da planilha, recomendamos um programa compatível com arquivos .xlsx. Algumas funções podem variar entre aplicativos.

Os materiais garantem resultados?

Não. Os guias são educativos e a planilha é uma ferramenta de organização. Resultados dependem do uso e das circunstâncias de cada pessoa.
